Description

COMMANDS

ns_valid_utf8 string ?varname?

Checks whether the provided argument (a Tcl byte-array) contains a valid UTF-8 code). The function returns a boolean result. When the optional varname is specified, a variable with this name is set in failure cases to the invalid part of the input value.

Note that this function only makes sense when applied on binary data, typically read from a socket or a file.
