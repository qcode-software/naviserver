Name

ns_sleep - Sleep for a specified number of seconds

Table Of Contents

  • Table Of Contents
  • Synopsis
  • Description
  • COMMANDS

Synopsis

  • ns_sleep duration

Description

Sleeps for a specified time period.

COMMANDS

ns_sleep duration

The duration can be specified with time units (per default seconds).

EXAMPLES

 % ns_sleep 2

See Also

ns_time, nsd

Keywords

global built-in, time
