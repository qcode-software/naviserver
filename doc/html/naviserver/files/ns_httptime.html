Name

ns_httptime - Convert seconds to HTTP date format

Table Of Contents

  • Table Of Contents
  • Synopsis
  • Description
  • COMMANDS
  • See Also
  • Keywords

Synopsis

  • ns_httptime time

Description

This command converts the time, specified as the number of seconds from 00:00:00 UTC Jan 1, 1970, to a string in HTTP date format.

COMMANDS

ns_httptime time

See Also

ns_fmttime, ns_localtime, ns_parsehttptime, ns_time

Keywords

global built-in, time
