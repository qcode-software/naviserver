NaviServer Frequently-Asked Questions and Answers

Getting NaviServer

NaviServer binary builds for many platforms are at https://sourceforge.net/projects/naviserver/.

Building NaviServer

NaviServer builds very easily and the online documentation describes the process. We recommend that you use the defaults in include/Makefile.global when building your module. This file contains rules and knows how to build modules properly for all platforms NaviServer has been ported to. The basic build and install instructions are available at https://github.com/naviserver-project/naviserver.

Getting Help

NaviServer has an active developer community as well as a very active user community. Links to these areas are at https://sourceforge.net/p/naviserver/mailman/naviserver-devel/.

Contributing Software

NaviServer is extremely extensible and we host a great many community-contributed modules https://github.com/orgs/naviserver-project/repositories. Feedback and pull requests can be provided on this channel as well.

Contributing Patches

We accept any form of patches via the source forge mailing list or via the GitHub repositories https://github.com/orgs/naviserver-project/repositories.
